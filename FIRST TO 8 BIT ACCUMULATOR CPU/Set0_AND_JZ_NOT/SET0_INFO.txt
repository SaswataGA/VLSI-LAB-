MINI 8-BIT ACCUMULATOR CPU  -  SET 0
============================================================
Complete instruction set : LDI, ADD, AND, JZ, NOT
Mandatory                : LDI, ADD
Assigned (Set 0)         : AND, JZ, NOT

ISE project file : cpu_set0.xise   (open with File > Open Project in ISE 14.7)
Top module       : cpu        (CLK, RESET, Q[7:0] = ACC, Z, PC[3:0])
Main testbench   : cpu_tb    (runs the Appendix B program and checks every cycle)

PROGRAM ROM (Appendix B)
------------------------------------------------------------
   0: LDI 0xA5   -> 0x1A5
   1: AND 0x5A   -> 0x45A
   2: JZ 0x05    -> 0xC05
   3: ADD 0x01   -> 0x201
   4: ADD 0x01   -> 0x201
   5: NOT        -> 0x700
   6: AND 0x0F   -> 0x40F
   7: JZ 0x00    -> 0xC00
   8: ADD 0x01   -> 0x201
  all other addresses: 0x000 (NOP)

HOW TO SIMULATE IN ISE 14.7
------------------------------------------------------------
  1. File > Open Project > cpu_set0.xise
  2. In the Design panel choose "Simulation" (not Implementation).
  3. Select  cpu_tb  ->  Processes: ISim Simulator -> Simulate Behavioral Model.
  4. In the ISim console you will see one line per cycle ("... | OK") and a final
     "PASS: cpu testbench completed" line.  Waveform signals: CLK, RESET, PC, ACC, Z.
  5. Click "Zoom to Full View" (or Home) to see all cycles, then take the screenshot.
     Signals are undefined (red) only for the first 1 ns, before the RESET edge - that is normal.
     The exp_acc / exp_z / exp_pc signals show the Appendix B values for comparison.
